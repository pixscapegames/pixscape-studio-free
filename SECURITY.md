# Security Policy

Please report security vulnerabilities privately before disclosing them
publicly.

Email reports to info@pixscape.games with a clear subject such as:

```text
Security report: Pixscape Studio Free
```

Please include:

- The affected version or commit, if known
- Steps to reproduce
- Impact and expected behavior
- Any relevant logs or proof-of-concept details

Maintainers will review the report and respond as soon as practical. Please do
not open a public issue for a security vulnerability until maintainers have had
time to assess it.
